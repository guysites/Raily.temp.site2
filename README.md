# Raily — independent website iteration

This repository contains an independent iteration of the Raily website, based on version 6 of `guysites/Raily.temp.site`.

The original repository is not modified.

## What's included

- The original v6 pages, dark visual system, logo asset, homepage hero infographic and iceberg.
- A richer custom illustration for **A new interface is emerging**.
- Three large custom SVG illustrations for **Connect**, **Contextualize**, and **Expose & Control** on the Platform page.
- Subtle motion in the SVG data flows, plus restrained hover and scroll-friendly responsive behavior.
- Use Cases visual hierarchy that highlights Data & Content Providers and Research & Knowledge Organizations as the initial focus, while retaining the enterprise ecosystem opportunity.
- Customer Stories retain the existing Haaretz, Research & Knowledge, and Existing Vector Infrastructure material; internal editorial notes have been removed.

## Preview

When GitHub Pages is enabled for this repository, the site is available at:

https://guysites.github.io/Raily.temp.site2/

To enable it: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.

You can also open `index.html` directly from the repository or run a local static server from the repository root.
